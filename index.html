Project Overview

Main ne is project ko ek mukammal DevOps Pipeline ke through build kiya hai. Iska workflow kuch is tarah hai:

  • ✅ GitHub: Source code yahan maintain kiya gaya hai.
  • ✅ Jenkins: Code automatically pick hota hai jaise hi koi change ho.
  • ✅ Docker & Compose: Applications ko containerize karke manage kiya gaya.
  • ✅ Deployment: Jenkins ne code pick kar ke mere Client Machine par deploy kiya.
